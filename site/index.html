Sandboxes

A macOS app for managing Docker Sandboxes.

Install Latest Release View on GitHub

Requires macOS 26 or later.

Install

curl -fsSL https://geofflamrock.github.io/Sandboxes/install.sh | bash

View Source Other Ways to Install

Features

  • See the details of your sandboxes, including resource usage, network traffic, and the network and file system rules that apply to them.
  • Create new sandboxes quickly and easily.
  • Create and manage sandbox environment files and use them to create sandboxes.
  • Start, stop and remove sandboxes.
  • Publish a sandbox’s ports on your Mac when creating it or later, open them in your browser, and unpublish them.
  • Open an interactive shell inside a sandbox in your terminal.
  • Run a sandbox’s agent in your terminal, or open any sandbox in Claude Desktop.
  • Get notified when an agent makes a network request that needs approval, and approve or deny across the current or all sandboxes.
  • Manage global and sandbox specific secrets.
  • Manage global and sandbox specific network rules.
  • Manage MCP servers and configure sandboxes to use them.
  • Manage agent skills and choose how sandboxes share them.
  • View and change sbx settings, such as proxies and kit policy, and restart the daemon when a change needs it.
  • Install, upgrade and sign in to sbx from the app, and run diagnostics to find problems with your setup.

Requirements

  • macOS 26 or later.
  • The sbx CLI. Install it with Homebrew: brew install docker/tap/sbx, or from the app.
  • Claude Desktop v2.110.0 or later, to open sandboxes in Claude Desktop.

The README lists the sbx versions that some features need.

Other Ways to Install

Read the script first

Download the install script, read it, then run it:

curl -fsSL https://geofflamrock.github.io/Sandboxes/install.sh -o install.sh && bash install.sh

Download the DMG

  1. Download Sandboxes-<version>.dmg from the latest release.
  2. Open the DMG and drag Sandboxes onto Applications.
  3. Sandboxes isn’t notarised by Apple yet, so the first time you open it macOS blocks it. Click Done, then open System Settings › Privacy & Security and click Open Anyway. You only need to do this once.

The install script doesn’t need the last step, because macOS doesn’t flag downloads made with curl.
